**作成日**: 2026-07-12
**対象ページ**: `bingo.html`

## 1. 目的

エンジニアである作者の日常的な仕事風景（会社での出来事・開発中の出来事・
チーム/組織での出来事など）をお題にした「お仕事編」カテゴリを追加する。

現状ビンゴのカテゴリは 日常 / 気持ち / 都会 / 二人限定 / 沖縄 の5種。
これに **work（お仕事）** を追加する。

## 2. 設計方針

### 2.1 POOL_META への追加

`bingo.html` の POOL_META に以下エントリを追加するだけで、他ロジックは変更不要:

```js
const POOL_META = {
  everyday: { weekly: true,  random: [1, 2, 3], category: true },
  feelings: { weekly: true,  random: [1, 2],    category: true },
  city:     { weekly: false, random: [2, 3],    category: true },
  couple:   { weekly: true,  random: [3],       category: true },
  weekday:  { weekly: true,  random: [],        category: false },
  weekend:  { weekly: true,  random: [],        category: false },
  okinawa:  { weekly: false, random: [],        category: true },
  work:     { weekly: true,  random: [1, 2, 3], category: true },  // ★追加
  spring:   { seasonKey: true },
  summer:   { seasonKey: true },
  autumn:   { seasonKey: true },
  winter:   { seasonKey: true },
  lucky:    { special: 'lucky' },
};
```

- `weekly: true` → 週間ビンゴのプールに加わる（他の週間対象と一緒に抽選）
- `random: [1, 2, 3]` → 全難易度のランダムに含まれる
- `category: true` → カテゴリ別ビンゴのボタンが増える

### 2.2 UI 側の変更

`bingo.html` 691行目付近のカテゴリボタンHTMLに1つ追加:
```html
<div class="category-card" onclick="selectCategory('work')">
  <div class="category-emoji">💼</div>
  <div class="category-title">お仕事</div>
  <div class="category-subtitle">会社・開発</div>
</div>
```

また `regenerateCard` 内の catMap にも追加:
```js
const catMap = {
  '🌿 日常': 'everyday',
  '😊 気持ち': 'feelings',
  '🏙 都会': 'city',
  '❤️ 二人限定': 'couple',
  '🌺 沖縄': 'okinawa',
  '💼 お仕事': 'work'  // ★追加
};
```

### 2.3 POOLS に work エントリを追加

POOLS オブジェクト（bingo.html 806行目付近）に以下を挿入:

```js

  // ... 下記候補リスト
],
```

- `docs/SPEC.md` §4.6 ビンゴセクションでカテゴリ一覧を6種に更新

## 5. 補足

### 5.1 週間ビンゴでの露出頻度
現在の週間ビンゴプール（couple含む）が約 1531 + 1148 + 830 + 847 + 873 + 季節751 ≈ 5980 個。
これに work 400個を追加しても割合は6.7%程度なので、
5×5=25マスなら1〜2マス程度 work が混ざる想定。ちょうど良い。

### 5.2 ランダムでの露出頻度
`random: [1, 2, 3]` 指定なら全難易度に含まれる。難易度1（★）はプールが
狭いので work の露出が大きくなり、それが「お仕事っぽい」体験に寄与する。
難易度3ではより多様な項目に混ざる。

### 5.3 拡張の余地
将来的に更に細分化する場合:
- `work_meeting`（会議専門）
- `work_dev`（実装専門）
- `work_emotion`（メンタル・状態専門）
- `work_ops`（運用・トラブル）

これらは全て POOL_META にフラグを立てるだけで追加可能。
