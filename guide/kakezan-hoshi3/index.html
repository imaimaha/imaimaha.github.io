暗算ランナーで★3を取るコツ｜いちばん大きい道の9割をめざす

暗算ランナーの★3は、ゴールの数が「いちばん大きくなる道」の9割をこえたらもらえます。1回のまちがいで届かなくなることもあるので、どこで差がつくのかを知っておきましょう。

結論：毎回、その場で大きくなるほうを選ぶ

  • ★3の線は、そのステージでいちばん大きくなる道の9割です。
  • くぐったあとの数が大きくなるほう（「いいほう」）を、毎回選びます。
  • とくにはじめのほうのまちがいに気をつけます。あとに×のゲートが来ると、差も何倍にもなるからです。

＋と×、−と÷のくらべ方は「暗算ランナーのゲートの選び方」でくわしく説明しています。この記事では、★3にしぼって書きます。

★の決まり方

  • ★1：ゴールまで走りきる（クリア）。
  • ★2：ゴールの数が、いちばん大きくなる道の半分以上。
  • ★3：ゴールの数が、いちばん大きくなる道の9割以上。

★2と★3の線の数は、ステージを始める前の画面に出ています。走り終わったあとの画面にも「あと○○で★3」と出るので、どれくらい足りなかったかがわかります。

境目の早見表

左右のゲートで迷うのは、＋と×、−と÷の組です。どちらが大きくなるかは、今の数が「境目」より大きいか小さいかで決まります。

ゲート境目今の数が境目より大きいとき
＋6 と ×26×2
＋12 と ×36×3
＋30 と ×410×4
−8 と ÷216−8
−10 と ÷315−10
−20 と ÷525−20

境目の出し方は、＋と×なら「たす数 ÷（かける数 − 1）」、−と÷なら「ひく数 × わる数 ÷（わる数 − 1）」です。ちょうど境目なら、どちらを選んでも同じ数になります。

ざっくり覚えるなら、数が大きくなってきたら×、へるときは−がたいてい得です。＋と＋、×と×のように同じ記号どうしなら、大きい数のほうを選ぶだけです。÷と÷なら、小さい数でわるほうです。

はじめのまちがいほど、あとまでひびく

今の数が10で、「＋5」と「×2」が来たとします。×2なら20、＋5なら15です。このあと「×3」が来ると、60と45。さらに×が続いても、15のほうの道は、ずっと20のほうの4分の3のままです。

★3の線は9割なので、この1回のまちがいだけで届かなくなるかもしれません。数が小さいはじめのうちは、差が5くらいでも、ゴールではとても大きな差になります。はじめの数ゲートこそ、ゆっくり確かめましょう。

フィーバーも、いいほうを選び続けてこそ

いいほうを選び続けると、ときどきフィーバー（×1.2）が入ります。悪いほうを選ぶと、フィーバーまでの数えがやりなおしになります。×1.2は、今の数が大きいほど大きくふえるので、数を大きく保っておくほど得です。

命がけゲートと大きな−

  • 命がけゲートは、片方をくぐると即アウトです。まず「今の数以上を引く」「今の数より大きい数でわる」ほうを消します。
  • ステージが進むと、どちらも大きく引くゲートが出てきます。前に小さいほうを選んでいると、ここで数が足りなくなって、アウトになることがあります。

どちらも、ふだんから数を大きくしておけば、こわくありません。

★3が取れないときの見直し方

  1. 結果の画面で「あと○○で★3」を見て、どれくらい足りないかを知る。
  2. 足りないのが少しなら、どこか1か所の迷いです。はじめのほうの＋と×を思い出してみます。
  3. 大きく足りないなら、−と÷の組で、のこる数が少ないほうを選んでいないかを見直します。
  4. 速さについていけないときは、境目の早見表の数を先に覚えておくと、判断が速くなります。

暗算ランナー

左右の計算ゲートの得なほうをくぐって、数をふやす暗算ランゲーム。全200ステージ。毎日の「今日のステージ」は、みんな同じコースで、こえたゲートの数をランキングでくらべます。無料（広告あり）の iPhone アプリです。

よくある質問

★3の線は、どこで見られますか？

ステージを始める前の画面に、★2と★3になるゴールの数が出ています。走り終わったあとの画面にも、あといくつで次の★かが出ます。

復活したあとでも、★はもらえますか？

ステージでは、動画で1回だけ復活して、そのままゴールすれば★がもらえます。★の数は、ゴールの数で決まります。

一度とった★はへりますか？

へりません。同じステージをもう一度走って、前より少ない★だったときも、いちばん多い★が残ります。
